Rerun from a fresh checkout (bash, Python 3.10+):

  git clone https://github.com/mitchell-d00/The-Seat-Is-Not-a-Costume-Enforced-and-Requested-Contracts-in-Multi-Seat-Language-Model-Play.git seat-contracts
  cd seat-contracts
  # Apply only if the checkout still uses sec/:
  if [ -d sec ] && [ ! -e src ]; then mv sec src; fi
  python3 -m venv .venv
  source .venv/bin/activate
  python -m pip install -e '.[dev]'
  python -m pytest -q
  python experiments/preflight.py --backends mock
  python experiments/judge_check.py --judge-backend rule
  mkdir -p results/offline-validation
  for e in e1_leak_probe e2_attribution e3_instrument_symmetry; do
    python experiments/$e.py --backend mock --judge-backend rule --scenes 40 --turns 24 --cache .cache/offline-validation --out results/offline-validation/${e%%_*}.json
  done
  python experiments/e4_externalization.py --backend mock --scenes 40 --turns 24 --cache .cache/offline-validation --out results/offline-validation/e4.json

Known protocol gaps, unchanged:
- P6 at L1 cannot distinguish private vs shared buffers in this implementation.
- P8 equivalence margin has not been selected; the run reports but does not
  decide equivalence.
- E4 does not implement the paper's eight-turn continuation; convention
  survival is scored by presence in the reseeding context.

Before future live data collection: choose test models from at least two
families and a separate qualified judge; provide credentials in your own
runtime; resolve the P6 scope and P8 margin before freezing the protocol.
Then install '.[live]', pass the live judge check, finalize and check the
preregistration lock, run preflight and a small pilot, and use the cross-family
runner for the full grid. Live runs incur provider charges; none were made here.

Included files: this guide, e1-e4 JSON results, E1 audit JSONL, execution logs,
and the rule-judge calibration record. Responses are cached in the local
checkout; the cache is omitted from this bundle. A cached rerun is a replay,
not an independent replication.
